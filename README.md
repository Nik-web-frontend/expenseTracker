# JavaScript Expense Tracker

A fully functional Expense Tracker built using Vanilla JavaScript.  
The application allows users to add, edit, delete, search, filter, and sort transactions while storing data in localStorage.

## Features

- Add income and expense transactions
- Edit existing transactions
- Delete transactions
- Search transactions by description and amount
- Filter by income and expense
- Sort transactions by date
- Real-time balance calculation
- Persistent data using localStorage

## Tech Stack
- HTML
- CSS
- JavaScript
